# B476 — Language Outcome Learning GOLD

B476 closes the WELTFORMEL language loop from interpretation to verified learning evidence.

```text
Utterance
 -> B469 realization
 -> B470 proposition graph
 -> B471 exact reference grounding
 -> B472 state sufficiency
 -> B473 world convergence
 -> B474 temporal/modal reality
 -> action / owner feedback / later outcome
 -> WorldGroundedLanguageLearningEvidence
 -> existing personal-language support policy
 -> existing shadow regression gate
 -> durable lexicon CAS promotion
 -> exact rollback remains available
```

Positive learning evidence can come from:

1. explicit Owner confirmation, which is authoritative for personal language meaning but **not** for
   external world truth; or
2. a verified outcome, but only when the interpretation lattice is converged, not world-blocked,
   all selected references are exact revision-grounded, and structural reference/condition/role
   gaps are resolved.

Owner correction and rejection are negative evidence and veto outcome-guarded promotion.

The new outcome gate does not replace the existing repeated-observation policy, shadow holdout,
no-new-external-effect checks or durable CAS head. It adds another evidence condition in front of
those authorities.

GOLD proves that an eligible personal alias can promote through the existing durable pipeline and
that rollback moves the durable head back to the exact previous lexicon while retaining the promoted
snapshot for audit/recovery.

Hard invariants:

- owner confirmation != external world truth
- verified outcome without resolved grounding cannot train positively
- correction/rejection cannot become positive evidence
- learning evidence has no lexical/grammar promotion authority by itself
- promotion still requires existing policy + shadow validation
- promotion grants no external-effect authority
- durable rollback preserves prior and promoted snapshots exactly
